                Пример промта для генерации страницы
                
Создай один автономный адаптивный index.html без внешних библиотек и сетевых шрифтов. Это красивая аллегорическая страница о свободном маршруте: без прямых политических лозунгов, хорошо выглядит на телефоне и ПК, быстро загружается. Добавь одну большую CTA-кнопку со ссылкой __PROXY_LINK__ и рядом кнопку копирования этой ссылки в буфер. Весь CSS и JavaScript помести внутрь HTML.
